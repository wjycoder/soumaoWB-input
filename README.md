# 搜猫五笔 1.3.1

完全离线、独立开发的 macOS 原生五笔输入法。支持 macOS 14 及更新版本，安装包同时包含 Apple Silicon 与 Intel 可执行代码。

## 安装与添加

1. 双击本目录的 **搜猫五笔-1.3.1.pkg**，按安装器提示安装，系统会要求管理员授权。
   升级前先切换到其他输入法，安装完成后注销并重新登录，以加载新版进程；个人词库会保留。
2. 打开 **系统设置 → 键盘 → 文本输入 → 编辑 → ＋ → 简体中文**，选择“搜猫五笔”并添加。
3. 从菜单栏输入法菜单切换到搜猫五笔。如果没有出现，请注销当前账户后重新登录，再添加。
4. 从搜猫五笔的输入法菜单选择 **偏好设置…**。

安装位置：`/Library/Input Methods/SoumaoWubi.app`。安装器只尝试注册输入源，不自动切换当前输入法。应用为本地 ad-hoc 签名，安装包未使用 Developer ID 签名，也未进行 Apple 公证。若 macOS 拦截，按“系统设置 → 隐私与安全性”中系统提供的允许打开流程处理。

## 1.3.1 兼容性修复

修复 SecureCRT 中中英文输入异常、仅 a 等少数按键可用的问题。每次激活输入会话时显式指定 ABC 底层键盘布局，供 Qt 客户端转换按键。已在 SecureCRT 9.5.1 本地 Telnet 测试中验证五笔 `lwty`＋空格提交“输入”，Shift 切英文后 `abcxyz123` 完整送达接收端。详见 [1.3.1 验收记录](docs/验收记录-1.3.1.md)。

## 输入和词库管理

- 输入 1–4 位五笔编码（a–y，或用 z 通配）；每页 5 个候选，空格选当前页首词，1–5 选词，分号 `;` 选当前页第二词。
- **z 通配键**：每个 `z` 代替任意一位 `a–y`，支持任意位置和多个 `z`。例如 `sz` 可查到 `械(sa)`、`林(ss)`、`枯(sd)`。同长度匹配优先，再列较长编码的联想候选；通配候选显示实际编码。按 `z` 进入组字，含 `z` 的四码不触发唯一候选自动上屏，可用空格、数字或分号选词；第五码沿用提交当前候选并开始新组字的规则。Return 或 Shift 可主动上屏原始编码。英文及临时拼音中的 `z` 用法不变，词库管理仍使用实际 a–y 编码。
- `[` / `]`（中文标点为 `【` / `】`）、`-` / `=` 或 Page Up / Page Down 翻页；退格改码，Esc 取消，Return 输出原始编码。候选窗横排显示候选及编号，每页 5 个；完整匹配优先，其后联想较长编码的字词。联想及通配候选显示括号编码，例如 `输入(lwty)`；真正无匹配时隐藏。
- 无编码时单击 Shift 切换中英文；有未上屏编码时，Shift 直接输出原始编码并切换到英文。Shift 组合键不会触发模式切换。Caps Lock 为英文。快捷键 Command / Control / Option 交回应用处理。
- 不再显示常驻菜单栏状态。单击 Shift 成功切换时，在当前屏幕短暂显示“中文”或“ABC”，约 0.8 秒自动消失，不抢输入焦点。偏好设置仍在系统输入法菜单中。
- 中文模式 `/` 输出 `、`；直接输入数字后紧接的句点仅一次输出英文 `.`，之后恢复 `。`。数字选词不会触发该例外。
- 单击 Ctrl 临时使用全拼：已有编码保持不变并按拼音重新匹配；空闲时对下一次组字有效。选词、取消、删除全部编码、切换模式或离开输入会话后恢复五笔。Ctrl 组合快捷键不触发临时拼音。支持长拼音、`z`、音节分隔符 `'`，ü 用 `v`（如 `nv`、`lvse`）。
- 标点自动跟随中英文模式：中文输入使用中文标点，ABC 使用英文标点；旧版独立标点开关不再使用。常规设置仍可开启“四码唯一候选自动上屏”。
- **偏好设置 → 高级设置**：按编码查询同码词，选择可用词后用“上移 / 下移”调整候选顺序，立即保存；也可删除或恢复。输入编码和词语后点“造词”，新词优先显示。
- 删除只影响当前编码与词语的组合，其他编码下的同词保持可用；基础资源不被改写。
- 支持导出/导入用户词库 JSON。导入合并自造词、删除记录和自定义词序，保留原有自造词；同一编码的词序以导入文件为准，已删除记录优先。兼容 1.0.0 用户词库文件。不会下载任何词库。

临时拼音使用随包附带的 107,728 条静态拼音词条，由内置词库通过 macOS 汉字转拼音生成；支持全拼和前缀候选，不包含智能组句或多音字的全部读音。词库管理中的造词、删除和排序针对五笔编码，临时拼音使用内置静态词库。

用户数据位置：`~/Library/Application Support/SoumaoWubi/user-dictionary.json`。设置另存于应用自身的本地偏好域。用户数据损坏会明确报错并保留原文件；可以退出输入法后，用先前导出的 JSON 备份恢复上述文件。保存采用文件锁和原子替换。

## 离线保证与来源

词库内置 **112,014 个编码/词语配对**。默认保留词库基础排名和显式简码优先，支持手动调整同码候选顺序

程序启动前加载 macOS Seatbelt `deny network*` 规则，加载失败则停止运行。没有账号、遥测、在线更新、联网词库或远程资源代码。已实际测试 IPv4/IPv6 TCP、UDP 出站及入站绑定均被系统拒绝。

## 源码、构建与检查

`Sources/` 为独立 Swift/AppKit/InputMethodKit 与 C 源码；`Resources/wubi.tsv` 为内置离线数据；`Tests/` 为核心及原生控件测试。构建只使用本机 Apple Command Line Tools，不下载依赖。

```sh
bash scripts/build.sh
bash scripts/test.sh
```

从已安装应用运行启动诊断（此命令短暂打开偏好设置后退出，不修改词库）：

```sh
"/Library/Input Methods/SoumaoWubi.app/Contents/MacOS/SoumaoWubi" --diagnose
```

若已有输入法进程正在运行，建议先切换到其他输入法，避免同名输入服务冲突。网络自检无需启动输入服务：

```sh
"/Library/Input Methods/SoumaoWubi.app/Contents/MacOS/SoumaoWubi" --network-self-test
```

调试工具自身若已运行在其他 Seatbelt 沙箱内，系统可能拒绝再次加载沙箱；这是故意停止启动，不会回退为允许联网。正常 macOS 用户进程路径已验证。

## 验证范围

1.3.1 已通过：51 项核心行为、47 项输入策略、22 项真实 IMK 控制器与记录客户端的边界检查、28 项前缀与拼音集成、75 项 z 通配检查、46 项 AppKit 控件检查，共 269 项；另通过系统级网络拒绝、Apple Silicon/Intel 双架构构建、代码签名及安装包展开校验。

在本机 SecureCRT 9.5.1（Qt 6.5）中，通过已注册输入源运行修复副本，用户实际按键输入后，本地 Telnet 接收端完整收到“输入abcxyz123”。未执行新安装包的管理员级实际安装及安装后重新添加输入源流程；Intel 架构未进行 SecureCRT 实机输入验证。升级请按上面的步骤注销并重新登录。本次证据见 [1.3.1 验收记录](docs/验收记录-1.3.1.md)。

卸载时，先在系统设置中移除“搜猫五笔”，然后删除安装目录的 app；个人词库可以单独保留备份。
