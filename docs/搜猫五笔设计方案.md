# 搜猫五笔：独立 macOS 输入法

## 需求与范围

依据本机 `/Library/Input Methods/SogouWBInput.app`（1.4.0.148）研究词库格式与系统注册信息；重新编写输入法、候选窗、偏好设置和安装脚本。交付安装包至本目录，并保留可复现源码。不复制搜狗的可执行代码、图标和设置界面。

## 方案比较

1. **原生 InputMethodKit + Swift/AppKit（推荐）**：独立输入引擎，直接使用提取的搜狗五笔编码/词条数据；依赖少，词库删除和造词行为可控。
2. **InputMethodKit + Rime**：成熟输入引擎，但需引入和构建额外依赖、转换词库与定制管理接口；对本次功能范围收益有限。

## 推荐方案

- 独立标识 `com.soumao.inputmethod.Wubi`，显示名称“搜猫五笔”，提供 Apple Silicon 与 Intel 通用构建（macOS 14 或更新版本）。
- 基础词库来自本机搜狗 `Contents/Resources/wubi.dic`；完整解析并校验格式后转换为应用只读资源，保留来源摘要。若解析不能完整验证，继续调查，不以其他五笔词库替代。
- 输入支持 a–y 五笔编码、候选分页、空格首选、数字选词、退格、Escape 取消、Return 编码上屏、四码唯一候选自动上屏选项、中英文切换和中文标点。
- 偏好设置包含“常规”“高级设置”“关于”。高级设置提供编码查询、同码候选列表、删除所选词条、手动输入编码与词语造词、恢复被删除词条、用户改动导入导出。造词可以手动指定编码；不承诺自动推导任意词语编码。
- 基础词库只读，用户新增词和删除标记单独持久化；删除精确作用于“编码 + 词语”，不会误删其他编码下的同词；保存后输入引擎重新加载。损坏数据应明确报错并保留原文件。
- 原生安装包将输入法放入 `/Library/Input Methods/`，按 macOS 输入法机制声明连接名、控制器、输入模式与简体中文语言。安装后可在“系统设置 → 键盘 → 文本输入 → 编辑 → + → 简体中文”添加；系统缓存可能要求注销后重新登录。
- 当前机器没有可用 Developer ID 签名证书，因此构建采用本地 ad-hoc 签名；安装包不宣称已 Apple 公证。

2. 输入状态、选词、分页、增词、精确删词、恢复、重启持久化、错误处理测试。
3. 两种架构编译、bundle 元数据、链接与签名、安装包展开后的路径和文件校验。
4. 在当前权限允许范围内启动新应用并验证管理界面。实际安装、系统输入源发现和真实跨应用输入须以可执行的本机验证结果为准，未做的部分明确注明。

## 用户追加约束：完全离线

应用不可联网。词库内置，所有用户数据仅存本地；没有云候选、账号、遥测、远程词库下载和更新检查。主程序在任何 GUI 或输入服务初始化前应用 macOS Seatbelt `deny network*` 规则；规则加载失败即退出。构建验证应测试 TCP/UDP 网络调用被系统拒绝。该规则不妨碍系统输入法所需的本机 Mach IPC。
