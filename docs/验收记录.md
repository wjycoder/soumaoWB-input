## 安装后的人工验收

1. 安装 pkg，按 README 在系统设置添加搜猫五笔；如缓存未刷新，注销再登录。
2. 在文本编辑和浏览器文本框输入 `khlg`，空格应提交“中国”，数字选择对应同码候选。
3. 在高级设置查 `khlg`，删除“中国”，返回文本框确认其不再出现在该编码的候选中；恢复后重新出现。
4. 造词 `aaaa → 搜猫离线测试`，返回文本框确认其优先出现；注销登录后再次确认。
5. 验证 Shift 切换、分页、中文标点、复制粘贴快捷键和不同应用间切换。
