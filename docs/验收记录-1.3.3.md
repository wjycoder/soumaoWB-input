# 搜猫五笔 1.3.3 验收记录

日期：2026-11-19。依据根目录 feat.md 实施。已有 1.3.2 安装包，本次发布版本递增为 1.3.3，构建号 6。

## 改动

- 中文候选窗置顶。旧实现先设置菜单层级，再启用 isFloatingPanel；原生测试实测实际层级被重置为 3。现在先设置浮窗属性，最后指定 screenSaver 层级 1000，保持不激活、不抢主窗口、跨 Space 和全屏辅助窗口行为。
- 词库管理的内置词条来源统一为“基础词库”，自造词来源保持“自造词”。关于页与安装说明同步更新。
- 清理内置词库中的六条旧品牌词条，五笔资源由 112,014 配对变为 112,008，重新生成的静态拼音资源为 107,722 条。个人词库数据与导入、导出格式不变。
- 应用版本、安装器元数据、构建脚本、README 与校验文件同步更新。历史调研证据和历史版本验收资料保留原始内容，不随安装包分发。
