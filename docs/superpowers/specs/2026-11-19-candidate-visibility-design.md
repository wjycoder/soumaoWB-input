# 候选窗置顶与基础词库显示

依据根目录 feat.md 执行本次修复，发布版本 1.3.3（已有 1.3.2 安装包），构建号 6。

候选窗原先先设置菜单层级 101，再设置 isFloatingPanel；实测后一步会将实际层级重置为 3，因而会被应用浮层遮挡。在 isFloatingPanel 之后将候选窗设为 AppKit 的 screenSaver 层级 1000，继续使用非激活 NSPanel、跨 Space 和全屏辅助窗口行为。候选内容更新时继续 orderFrontRegardless，不改变选词、定位和隐藏流程。仅重复前置无法越过更高层级；使用最大整数层级没有必要。

词库管理中的内置来源统一显示为“基础词库”，自造词仍显示“自造词”。清理关于页、安装说明以及内置词库中的相关品牌词条，重新生成拼音数据；不改写用户个人词库。

在原生 AppKit 测试中创建与候选窗重叠的高层浮窗，通过 Window Server 窗口顺序验证候选窗在前，并检查不抢焦点、点击选词、隐藏和再次显示。运行完整测试，生成 Apple Silicon / Intel 通用安装包，展开核对版本、资源与签名，输出 SHA-256。

历史研究资料的清理范围由用户的补充选择决定；默认保留原始研究证据。新版应用及安装资源不携带历史研究资料。
