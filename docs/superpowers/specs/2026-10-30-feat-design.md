# feat.md 输入与偏好设置改进方案

依据：项目根目录 feat.md。状态：用户已确认，按推荐兼容规则实施。

## 输入行为

- 中文模式下，反引号 ` 输出中点 ·；有组字时沿用现有标点规则，先提交当前候选再输出中点。英文模式和 Caps Lock 继续透传。
- 中文组字时，半角分号 ; 和全角分号 ；选择当前页第二候选。半角单引号 ' 和中文左单引号 ‘ 选择当前页第三候选。
- 候选不足时消费选词键、保留组字和页码，不误提交首词或标点。无组字时维持原有标点行为。
- 推荐兼容规则：临时拼音中的半角单引号仍作为音节分隔符；五笔组字时作为第三候选快捷键。中文左单引号可用于拼音第三候选。另一方案是所有中文组字统一单引号选第三候选，但会失去原有拼音分隔输入能力；不建议新增设置开关增加复杂度。

## 偏好设置

- 将词库管理的查询、排序、删除、恢复、造词、导入和导出整体放入常规页。
- 保留四码唯一候选自动上屏复选框。
- 删除输入快捷键标题、所属两段说明及 feat.md 指定的标点提示。
- 高级设置现仅包含词库管理，迁移后移除空页，保留常规和关于两个标签。
- 常规页使用紧凑间距，必要时调整布局，确保最小窗口尺寸下所有操作可见。

## 实现范围与验证

- Sources/InputSession.swift：扩展标点和候选选择映射。
- Sources/Preferences.swift：合并常规页与词库页，保持词库持久化和各操作实现不变。
- Tests/InputTests.swift：覆盖中点、第二/第三候选、翻页、候选不足、英文透传和拼音兼容。
- Tests/PreferencesSmoke.swift：验证词库控件在常规页、两个标签、最小窗口布局及已有词库操作。
- README.md：同步按键规则与词库入口。
- 执行 scripts/test.sh 与 scripts/build.sh，检查原生设置页渲染。此任务不自动安装或重启系统输入法。

## 方案选择

推荐在现有 InputSession 与 AppKit 控件内做局部修改。相比重写设置页，改动更集中且复用已有测试；相比保留空高级页，移除空标签能避免无内容入口。
