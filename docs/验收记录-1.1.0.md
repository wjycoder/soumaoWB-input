## 五项需求

| 需求 | 实现 |
|---|---|
| Shift 提交编码 | 有编码时单击 Shift 输出原始编码并进入英文，不选择当前中文候选；组合按键不切换模式。 |
| 简化候选窗 | 仅保留横排候选和 1–5 选词编号，无名称、编码、页码或翻页提示；支持 `[ / ]`、`【 / 】`、`- / =` 和 Page Up / Page Down。无候选时隐藏。 |
| 中英文切换与状态 | 无编码时 Shift 切换；右侧菜单栏独立状态项显示“中文输入”或“ABC”；切走输入法时隐藏，Caps Lock 显示 ABC。 |
| 标点跟随模式 | 中文模式转换中文标点，英文和 Caps Lock 透传英文标点；移除独立标点偏好开关。 |
| 重码词排序 | 高级设置增加上移、下移，选择随词条移动；首尾及已删除词条禁用对应按钮。排序立即保存，重启及导出导入保留。 |

旧版用户 JSON 无需手工迁移。新增可选 `orders` 字段。导入合并自造词和删除记录，同码词序采用导入值；删除记录优先。新造词仍优先显示。修改在文件锁内读取最新文件并原子保存，不改内置词库。
