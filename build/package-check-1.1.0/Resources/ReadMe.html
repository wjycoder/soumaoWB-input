搜猫五笔

1.1.0 · macOS 14 或更高版本 · Apple 芯片与 Intel Mac

独立构建的五笔输入法，内置由本机搜狗五笔词库转换的数据。不是搜狗应用的改名版本，与搜狗公司无隶属关系。

完全离线

应用在本机完成编码查询、候选选择和词库管理，运行时禁止网络访问。无需登录账号，不提供云同步、联网更新或遥测。安装包已包含词库，安装和使用无需下载任何组件。

安装与添加输入法

  1. 本安装程序将输入法安装到 /Library/Input Methods/SoumaoWubi.app，需要管理员授权。
  2. 安装完成后，打开“系统设置” → “键盘” → “文本输入” → “编辑”，点击“＋”，在“简体中文”中选择“搜猫五笔”并添加。
  3. 如果列表中尚未出现“搜猫五笔”，请注销并重新登录，再打开上述设置。系统版本不同，设置名称可能略有差异。
  4. 从菜单栏输入法菜单选择“搜猫五笔”开始使用。安装程序只注册输入源，不会自动启用输入法或切换当前输入法。

1.1.0 输入改进

Shift 在有编码时直接上屏原始编码并切到英文，无编码时切换中英文；菜单栏状态显示“中文输入”或“ABC”。标点跟随当前模式。候选窗每页横排 5 个词，用 [ / ]（【 / 】）、- / = 翻页。

升级前请切换到其他输入法。安装后注销并重新登录，以加载新版本；个人词库和设置会保留。

偏好设置与词库管理

切换到搜猫五笔后，在菜单栏输入法菜单中选择“偏好设置…”。

打开“高级设置”，输入五笔编码即可查看对应重码词，选择指定词条后使用“上移 / 下移”调整候选顺序，或删除、恢复；输入编码和词语可自行造词。删除内置词条会保存为本地屏蔽记录，不会修改搜狗输入法或原始词库。可通过高级设置中的导入、导出功能备份个人调整。

个人词库

造词、删除记录及候选顺序按 macOS 用户分别保存在：

~/Library/Application Support/SoumaoWubi/user-dictionary.json

升级应用保留此目录中的个人数据。请勿在输入法运行期间手工修改该文件。

当前版本使用本地 ad-hoc 代码签名，安装包未进行 Developer ID 签名或 Apple 公证。
